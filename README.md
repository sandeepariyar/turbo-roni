# Turbo Roni — Speed Quest

A playful Android countdown app for Roni.

**Author:** Sandeep Pariyar

## Features in this repository
- Native Kotlin and Jetpack Compose UI
- Dressing, brushing teeth, cleanup, homework and other missions
- Ready / Set / Go countdown, pause/resume and finish
- Large countdown with animated orbiting particles and tap-to-spark interaction
- Personal best times saved on device
- Five selectable synthesized ticking styles and ticking interval settings
- Badges and simple reward progress

## Build
Open the repository in Android Studio (JDK 17), allow Gradle sync and run the `app` configuration on an Android device (Android 8+).

## Status
Source prototype. This commit has not been compiled or tested on a physical Android device. Android lock-screen/background countdown, notifications, audio timing, and reward security need further implementation and verification. Audio is generated with Android's built-in tone APIs rather than bundled copyrighted samples.
